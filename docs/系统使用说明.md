# InnerNet 1.0 系统使用说明

## 运行环境

- Windows 10/11 或 macOS
- Node.js `v24.19.0`
- 首次使用前在项目目录执行 `npm install`

## macOS 使用

双击 `启动 InnerNet.command`，或执行 `npm run runtime:check`、`npm run dev`。在“聚合挂载”中导入 Windows 清单，选择手动或自动挂载；群聊页面填写 Windows 服务端地址。

### 使用 release 产物安装

- `InnerNet-1.0.0-arm64.dmg`：双击打开，将“InnerNet 内网共享”拖入“应用程序”。
- `InnerNet-1.0.0-arm64.zip`：解压后，将 `InnerNet 内网共享.app` 拖入“应用程序”。

DMG 与 ZIP 内容相同，任选其一即可。当前版本未配置 Apple Developer ID 签名，首次打开若被拦截，请右键应用选择“打开”，或在“系统设置 → 隐私与安全性”中点击“仍要打开”。该 ARM64 版本适用于 Apple Silicon（M 系列）Mac；Intel Mac 需重新构建 x64 版本。

## Windows 使用

建议右键以管理员身份运行 `启动 InnerNet.bat`，或执行 `npm run runtime:check`、`npm run dev`。Windows 端负责 SMB 共享、共享清单接口和群聊服务；普通权限运行时高权限功能会受限。

### 使用 release 产物安装

- `InnerNet-Setup-1.0.0.exe`：右键选择“以管理员身份运行”，按向导安装。
- `win-unpacked/`：免安装目录，必须整体复制，运行其中的 `InnerNet 内网共享.exe`，不可只复制 exe 文件。

Windows 与 macOS 安装包不可混用，首次启动建议使用管理员权限。

## 群聊与数据

支持文字、图片、常见文本文件、压缩文件和文件夹拖拽发送，文件夹会压缩为 ZIP。Windows“记录管理”可查看本机数据位置、清理缓存并导出 JSON/Markdown 历史。

## 打包

macOS：`npm install` → `npm run check` → `npm run build:mac`；Windows：`npm install` → `npm run check` → `npm run build:win`。安装包输出到 `release/`。

`*.blockmap` 是更新辅助文件，请与对应安装包一起保留；`builder-*.yml`、`mac-arm64/` 和 `win-unpacked/` 属于构建辅助或免安装产物，普通用户只需安装包即可。

## 故障排查

先执行 `npm run runtime:check`；Electron 缺失执行 `npm run electron:ensure`。Windows 开发端口为 `6300`，聊天服务端口为 `7890`（共享清单接口同端口）。拉取清单失败时检查 IP、设备中心的配对状态和 Windows 端服务是否在运行；挂载失败时检查 IP、SMB 账号口令、SMB ACL 和 macOS 隐私权限。
